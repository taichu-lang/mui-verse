# SwipeableMenu

基于 MUI `SwipeableDrawer` 封装的滑出式菜单组件，API 与 [`DropdownMenu`](./DropdownMenu.mdx) 对齐，作为下拉菜单在移动端的等效替代。

桌面端用 `DropdownMenu` 弹出锚定式菜单，移动端切换为 `SwipeableMenu` 从屏幕边缘滑出抽屉，更符合手势交互习惯。两者的子组件命名一一对应：`Trigger`、`Content`、`Item`，便于结合 [`useMobile`](../src/hooks/useMobile.tsx) 在同一页面里按断点切换。

## 引入

```tsx
import {
  SwipeableMenu,
  SwipeableMenuTrigger,
  SwipeableMenuContent,
  SwipeableMenuItem,
} from "@mui-verse/ui/components/navigation";
```

## 基础用法

```tsx
<SwipeableMenu>
  <SwipeableMenuTrigger>
    <IconButton>
      <EllipsisIcon className="h-4 w-4" />
    </IconButton>
  </SwipeableMenuTrigger>
  <SwipeableMenuContent>
    <SwipeableMenuItem onClick={() => console.log("编辑")}>编辑</SwipeableMenuItem>
    <SwipeableMenuItem>复制</SwipeableMenuItem>
    <SwipeableMenuItem>删除</SwipeableMenuItem>
  </SwipeableMenuContent>
</SwipeableMenu>
```

## 作为 DropdownMenu 的移动端形态

结合 `useMobile` 按断点切换：桌面用 `DropdownMenu`，移动端用 `SwipeableMenu`。子组件命名几乎一致，可直接复用菜单项结构。

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
  SwipeableMenu,
  SwipeableMenuContent,
  SwipeableMenuItem,
  SwipeableMenuTrigger,
} from "@mui-verse/ui/components/navigation";
import { useMobile } from "@mui-verse/ui/hooks/useMobile";

export function SortMenu() {
  const isMobile = useMobile();

  if (isMobile) {
    return (
      <SwipeableMenu>
        <SwipeableMenuTrigger>
          <button>
            <EllipsisIcon className="h-4 w-4" />
          </button>
        </SwipeableMenuTrigger>
        <SwipeableMenuContent>
          <SwipeableMenuItem>名称</SwipeableMenuItem>
          <SwipeableMenuItem>上次浏览</SwipeableMenuItem>
          <SwipeableMenuItem>创建时间</SwipeableMenuItem>
        </SwipeableMenuContent>
      </SwipeableMenu>
    );
  }

  return (
    <DropdownMenu align="end" side="bottom">
      <DropdownMenuTrigger>
        <button>
          <EllipsisIcon className="h-4 w-4" />
        </button>
      </DropdownMenuTrigger>
      <DropdownMenuContent>
        <DropdownMenuItem>名称</DropdownMenuItem>
        <DropdownMenuItem>上次浏览</DropdownMenuItem>
        <DropdownMenuItem>创建时间</DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  );
}
```

## 滑出方向

通过 `side` 控制抽屉从屏幕的哪一侧滑出，默认 `bottom`。移动端通常推荐使用 `bottom`，更贴合拇指操作习惯。

```tsx
<SwipeableMenu side="bottom">
  {/* ... */}
</SwipeableMenu>
```

| 属性 | 可选值 | 默认值 |
| --- | --- | --- |
| `side` | `top` `right` `bottom` `left` | `bottom` |

> 与 `DropdownMenu` 不同，`SwipeableMenu` 没有 `align` 属性 —— 抽屉始终沿屏幕边缘铺满，不需要对齐方式。

## 带图标的菜单项

`SwipeableMenuItem` 内部使用 flex 布局（`gap: 1`），直接放入图标即可。

```tsx
import { Pencil, Copy, Trash2 } from "lucide-react";

<SwipeableMenu>
  <SwipeableMenuTrigger>
    <Button variant="outlined">操作</Button>
  </SwipeableMenuTrigger>
  <SwipeableMenuContent>
    <SwipeableMenuItem>
      <Pencil size={16} /> 编辑
    </SwipeableMenuItem>
    <SwipeableMenuItem>
      <Copy size={16} /> 复制
    </SwipeableMenuItem>
    <SwipeableMenuItem>
      <Trash2 size={16} /> 删除
    </SwipeableMenuItem>
  </SwipeableMenuContent>
</SwipeableMenu>
```

## 点击后不关闭菜单

将 `closeOnClick` 设为 `false`，点击该项后抽屉保持打开。

```tsx
<SwipeableMenuItem closeOnClick={false} onClick={() => toggle()}>
  启用通知
</SwipeableMenuItem>
```

## 自定义 Content 样式

`SwipeableMenuContent` 接受 `className`，会合并到内部 flex 容器上。常见用法是限制最大高度并允许滚动。

```tsx
<SwipeableMenuContent className="max-h-96 overflow-y-auto">
  {/* 大量菜单项 */}
</SwipeableMenuContent>
```

内置样式包含：

- 顶部 16px 圆角（仅当 `side="bottom"` 时视觉上明显）
- 半透明背景 + 16px 背景模糊（毛玻璃）
- 自动适配 light/dark 主题
- 隐形 backdrop（点击空白处仍可关闭，但不再有暗色蒙层）

## API

### SwipeableMenu

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `defaultOpen` | `boolean` | `false` | 初始是否展开 |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | 抽屉滑出方向 |

### SwipeableMenuTrigger

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `children` | `ReactElement` | 触发器元素，点击后打开抽屉 |

### SwipeableMenuContent

| 属性 | 类型 | 说明 |
| --- | --- | --- |
| `className` | `string` | 合并到内部 flex 容器上的类名 |
| `children` | `ReactNode` | 抽屉内容 |

### SwipeableMenuItem

继承 MUI `MenuItemProps`。

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `closeOnClick` | `boolean` | `true` | 点击后是否关闭抽屉 |

## 与 DropdownMenu 的差异

| | DropdownMenu | SwipeableMenu |
| --- | --- | --- |
| 适用场景 | 桌面端 | 移动端 / 触屏 |
| 弹出形式 | 锚定在 Trigger 旁的浮层 | 从屏幕边缘滑出的抽屉 |
| `side` | 浮层方向 | 抽屉滑出方向 |
| `align` | ✅ | ❌（抽屉沿边缘铺满） |
| 关闭方式 | 点击外部 / 选择菜单项 / Esc | 点击外部 / 选择菜单项 / 向下滑动 |
| 分隔线 | `DropdownMenuSeparator` | 暂未提供，复用 `DropdownMenuSeparator` 即可 |
| `onOpenChange` | ✅ | ❌（如有需要可后续补充） |
