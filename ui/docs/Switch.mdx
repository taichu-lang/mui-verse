# Switch

基于 MUI Switch 封装的开关组件，在原生能力之上提供更紧凑的 `inset` 变体，并默认关闭 ripple 与 hover 背景，使外观更贴合现代设计语言。

## 引入

```tsx
import { Switch } from "@mui-verse/ui/components/inputs";
```

## 基础用法

非受控用法，使用 `defaultChecked` 设置初始值：

```tsx
<Switch defaultChecked />
```

受控用法，配合 `useState` 管理状态：

```tsx
import { useState } from "react";
import { Switch } from "@mui-verse/ui/components/inputs";

export function NotificationToggle() {
  const [enabled, setEnabled] = useState(false);

  return (
    <Switch
      checked={enabled}
      onChange={(_, checked) => setEnabled(checked)}
    />
  );
}
```

## 变体

通过 `variant` 切换尺寸与样式。

```tsx
<Switch variant="standard" />
<Switch variant="inset" />
```

| 变体 | 尺寸 | 适用场景 |
| --- | --- | --- |
| `standard` | MUI 默认尺寸 | 表单、设置项等常规场景 |
| `inset` | 28 × 16，thumb 12 × 12 | 列表项、行内紧凑布局、Toolbar |

## 与 FormControlLabel 搭配

需要文字标签时，搭配 MUI 的 `FormControlLabel` 使用：

```tsx
import { FormControlLabel } from "@mui/material";
import { Switch } from "@mui-verse/ui/components/inputs";

<FormControlLabel
  control={<Switch />}
  label="启用通知"
/>
```

## 禁用状态

```tsx
<Switch disabled />
<Switch disabled defaultChecked />
```

## 自定义样式

`sx` 会与内置样式合并（数组形式），可以安全覆盖任意 slot：

```tsx
<Switch
  variant="inset"
  sx={{
    "& .MuiSwitch-track": {
      backgroundColor: "primary.light",
    },
  }}
/>
```

## 透传 ref

组件以普通 prop 形式接收 `ref`（React 19 + React Compiler 规范），可直接拿到底层 `<button>` 元素：

```tsx
const switchRef = useRef<HTMLButtonElement>(null);

<Switch ref={switchRef} />
```

## API

### Switch Props

继承 MUI `SwitchProps`，新增以下属性：

| 属性 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `variant` | `"standard" \| "inset"` | `"standard"` | 视觉变体。`inset` 为更紧凑的小尺寸样式 |
| `disableRipple` | `boolean` | `true` | 是否禁用 ripple 效果。默认禁用，同时去除 hover 背景 |
| `ref` | `React.Ref<HTMLButtonElement>` | - | 底层 button 元素的 ref |

其余属性（`checked`、`defaultChecked`、`onChange`、`disabled`、`color`、`size`、`sx` 等）与 MUI `Switch` 一致，参见 [MUI Switch 文档](https://mui.com/material-ui/api/switch/)。

### SwitchVariant

```ts
type SwitchVariant = "standard" | "inset";
```

## 设计说明

- **默认禁用 ripple**：与本设计体系内其他控件保持一致的“极简反馈”风格，避免点击时的水波扩散。同时移除了 `switchBase` 在 hover / checked + hover 时的背景色，使开关在密集列表中更安静。
- **`inset` 变体**：当 Switch 出现在列表项右侧、Toolbar 或行内表单中时，使用 `inset` 可避免控件视觉上“跳出”行高。
- **`sx` 合并策略**：内置样式以数组形式注入，外部传入的 `sx`（对象或数组）会拼接到末尾，因此用户的样式优先级始终最高。
